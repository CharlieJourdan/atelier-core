# Atelier music library

Three instrumental beds for narrated documentaries, loopable, about 40–45 s each, stereo 48 kHz, AAC `.m4a` at
160 kb/s, normalised to −20 LUFS integrated (the `sound.music` node sets them relative to the voice).

| id | file | mood | character |
|---|---|---|---|
| `atelier-reflective-1` | `reflective-1.m4a` | reflective | soft pad, slow arpeggio, a few high notes late in the loop |
| `atelier-tension-1` | `tension-1.m4a` | tension | low pulse, minor drone, sparse high bell notes |
| `atelier-hopeful-1` | `hopeful-1.m4a` | hopeful | warm major chords, gentle pluck rhythm |

`library.json` lists them (id, file, title, mood, duration, loop, licence, author, loudness).

## Provenance and licence

Every track is generated by our own script, `scripts/make-music.mjs`: plain sine synthesis, ADSR envelopes and a
feedback echo, with no sample, no recording and no third-party material. The result is deterministic (same script,
same audio) and seamlessly loopable.

## Regenerate

```
node scripts/make-music.mjs            # writes resources/music/*.m4a and library.json
```

Needs only the system `ffmpeg` on PATH. The script prints each track's duration, gain, measured loudness and size.
